# Unihockey Stats – Desktop-App (Download)

Hier liegt nur der Download der Windows-Desktop-App von **Unihockey Stats**
(Tore-Highlights, YouTube-Ausschnitte, Mediathek, Analyse-Studio).

**Download:** [UnihockeyStats-Portable.zip (neueste Version)](https://github.com/samsuel14/unihockeystats-desktop/releases/latest/download/UnihockeyStats-Portable.zip)

1. ZIP entpacken
2. `UnihockeyStats.exe` starten (Windows warnt evtl. beim ersten Start: „Weitere Informationen“ → „Trotzdem ausführen“)
3. Mit dem Konto der Web-App anmelden

Die App aktualisiert sich danach selbst (signierte Updates).
Web-App: https://uhcbsu-stats.vercel.app · Impressum/Datenschutz: siehe Web-App.
